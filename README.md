# Fraud Detection (Anomaly Detection)

Проект по обнаружению аномалий в транзакциях банковских карт с использованием методов машинного обучения.

## 📌 Описание

В работе исследуются и сравниваются методы обнаружения аномалий:

- Isolation Forest
- Local Outlier Factor (LOF)
- DBSCAN

Модель обучается на датасете кредитных транзакций и определяет подозрительные операции.

## 📊 Данные

Используется датасет:
Credit Card Fraud Detection (Kaggle)

⚠️ В проекте используется подмножество данных (~20 000 строк)

## ⚙️ Используемые технологии

- Python
- pandas
- scikit-learn
- numpy

## 🚀 Как запустить

1. Установить зависимости:
  ```pip install -r requirements.txt```

2. Запустить:
   ```python src/main.py```
   
## 📈 Результаты

| Метод | Precision | Recall | F1 |
|------|----------|--------|----|
| Isolation Forest | 0.5059 | 0.5059 | 0.5059 |
| LOF | 0.0000 | 0.0000 | 0.0000 |
| DBSCAN | 0.0300 | 0.9412 | 0.0582 |

## 💡 Выводы

- Isolation Forest показывает наиболее сбалансированный результат  
- DBSCAN хорошо находит аномалии (высокий recall), но много ложных срабатываний  
- LOF плохо справился с данной задачей
