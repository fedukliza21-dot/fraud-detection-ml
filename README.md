# 🚀 Fraud Detection ML API

**Система обнаружения аномалий (мошеннических транзакций) с REST API**

---

## 📌 О проекте

Проект представляет собой систему для обнаружения аномалий в финансовых транзакциях с использованием методов машинного обучения. Изначально созданый как научно-исследовательская работа в РТУ МИРЭА, 3 семестр (2 курс). Выполнено на оценку "отлично".

Реализовано:
- предобработка и нормализация данных  
- применение нескольких алгоритмов обнаружения аномалий  
- оценка качества моделей  
- REST API для получения предсказаний в реальном времени  

> ⚠️ Датасет содержит анонимизированные признаки (V1–V28), полученные с помощью PCA — это стандартный подход для финансовых данных.

---

## 🧠 Используемые методы

- **Isolation Forest** (основной)
- Local Outlier Factor (LOF)
- DBSCAN

Основной моделью выбран **Isolation Forest**, так как он показывает наиболее сбалансированные результаты.

## ⚙️ Установка

```
git clone https://github.com/fedukliza21-dot/fraud-detection-ml.git
cd fraud-detection-ml

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
```

## ▶️ Запуск ML pipeline
```
python src/main.py
```

## 🌐 Запуск API
```
uvicorn src.api:app --reload
```

После запуска открыть:
```
👉 http://127.0.0.1:8000/docs
```
